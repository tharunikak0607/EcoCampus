EcoCampus – Smart Campus Energy Monitoring System

About the Project

EcoCampus is a Java-based application designed to monitor and manage energy consumption in a smart campus.

Features

- Add Energy Readings
- View All Energy Readings
- Calculate Total Energy Consumption
- Detect Energy Anomalies
- Simulate Concurrent Meter Readings
- Handle Invalid and Duplicate Readings

Technologies Used

- Java
- Object-Oriented Programming
- Multithreading
- Exception Handling
- Collections

How to Run

1. Clone or download the repository.
2. Open the project in VS Code.
3. Compile the Java files.
4. Run the main application.

Project Type

Java Mini Project
